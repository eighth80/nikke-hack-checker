## 다운로드 / ダウンロード

| | |
|---|---|
| 🇰🇷 한국어판 | `nikke_check_ko.exe` |
| 🇯🇵 日本語版 | `nikke_check_ja.exe` |
| 🔐 해시 / ハッシュ | `SHA256SUMS.txt` |

exe 파일은 이 릴리스를 발행하면 GitHub Actions가 소스로 직접 빌드해서 몇 분 뒤 자동으로 첨부됩니다.
exeはこのリリースの公開後、GitHub Actionsがソースから直接ビルドして数分後に自動で添付されます。

---

### 🇰🇷 바뀐 점

- **오탐 수정**: 해결 후 다시 검사하면 "DNS 캐시 analytics.insightjs.com" 감염이 뜨던 문제. hosts로 막아 둔 주소는 이제 조회 기록으로 보지 않습니다.
- **오탐 수정**: 크롬의 정상 프로그램 `platform_experience_helper.exe`가 실행 중이면 "악성 DLL 로드됨"으로 잡히던 문제
- 검사가 끝나면 상세창에 **"이렇게 판단한 이유"**를 바로 표시
- 차단 상태를 항목별로 표시하고, 다른 점검 도구가 만든 방화벽 규칙도 인정
- 글자가 잘리던 화면 배치 수정
- 일본어판을 한국어판과 같은 기능으로 맞춤

> 이전 버전에서 "감염 흔적 1건 (DNS 캐시)"이 나왔다면 이 버전으로 다시 검사해 주세요.

### 🇯🇵 変更点

- **誤検知の修正**: 対処後にもう一度チェックすると「DNSキャッシュ analytics.insightjs.com」の感染が出ていた問題。hostsで遮断したアドレスは名前解決の記録と見なさなくなりました。
- **誤検知の修正**: Chromeの正常なプログラム `platform_experience_helper.exe` が実行中だと「悪意のあるDLLが読み込まれています」と判定されていた問題
- チェック後、詳細欄に **「こう判定した理由」** をすぐに表示
- 遮断状態を項目ごとに表示し、ほかのチェックツールが作ったファイアウォールルールも認識
- 文字が切れていた画面レイアウトを修正
- 日本語版を韓国語版と同じ機能にそろえました

> 以前のバージョンで「感染の痕跡 1件(DNSキャッシュ)」と出た場合は、このバージョンでもう一度チェックしてください。
